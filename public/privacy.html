Privacidad

corre, robby, corre · 27 de noviembre de 2026

En pocas palabras: el juego no recoge ningún dato de nadie. No hay cuentas, no hay anuncios y no hay ningún tipo de seguimiento.

Lo que el juego guarda

Todo esto se guarda solo en el teléfono, la tableta o la computadora donde se juega. Nunca se envía a nadie.

  • Los niveles pasados y las estampas ganadas.
  • Los ajustes: idioma, velocidad, sonido, música, personaje, juego y edad elegidos.
  • El nombre que se escribe para la tabla de récords y esos récords.

Al borrar los datos del navegador, o al borrar la app, todo eso desaparece.

Lo que el juego no hace

  • No pide nombre, correo, edad real, fotos, ubicación ni contactos.
  • No tiene anuncios.
  • No usa herramientas de medición ni de seguimiento, propias o de otras empresas.
  • No tiene compras.
  • No usa el micrófono ni la cámara.

La versión web

La página del juego está alojada en GitHub Pages. Como cualquier sitio web, la empresa que lo aloja (GitHub) registra datos técnicos de cada visita, como la dirección IP. El juego no recibe ni usa esos datos. Más información: declaración de privacidad de GitHub.

La app

Todo lo que el juego necesita viene dentro de la app. La app no se conecta a internet para funcionar.

Enlaces hacia afuera

Si el juego ofrece una página para apoyarlo, está en los ajustes, detrás de una pregunta para adultos, y se abre fuera del juego. Esa página tiene sus propias reglas de privacidad.

La voz

La voz del juego está hecha por computadora. No es la grabación de una persona.

Niñas y niños

El juego está hecho para niñas y niños pequeños. Como no recoge ningún dato, tampoco recoge datos de menores.

Contacto

Para preguntas sobre esta página: github.com/mindlesspawn/corre-robby-corre.

Privacy

corre, robby, corre · 27 November 2026

In short: the game collects no data from anyone. There are no accounts, no ads, and no tracking of any kind.

What the game saves

All of this is saved only on the phone, tablet or computer the game is played on. It is never sent anywhere.

  • The levels cleared and the stickers earned.
  • The settings: the chosen language, speed, sound, music, character, game and age.
  • The name typed for the high score table, and those scores.

Clearing the browser's data, or deleting the app, removes all of it.

What the game does not do

  • It does not ask for a name, email, real age, photos, location or contacts.
  • It has no ads.
  • It uses no analytics or tracking tools, its own or anyone else's.
  • It has no purchases.
  • It does not use the microphone or the camera.

The web version

The game's web page is hosted on GitHub Pages. Like any website, the company that hosts it (GitHub) logs technical details of each visit, such as the IP address. The game does not receive or use that information. More: GitHub's privacy statement.

The app

Everything the game needs is inside the app. The app does not connect to the internet to work.

Links out

If the game offers a page for supporting it, that page is in the settings, behind a question for grown-ups, and it opens outside the game. That page has its own privacy rules.

The voice

The game's voice is computer-generated. It is not a recording of a person.

Children

The game is made for young children. Because it collects no data at all, it collects none from children.

Contact

For questions about this page: github.com/mindlesspawn/corre-robby-corre.
